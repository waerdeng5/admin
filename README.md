# admin

Repository managed together with a DeepSeek Super-agent.

## Working with the agent

- Ask for work by commenting `@<agent login> <request>` on an issue or pull request.
- The agent works in its own branch (`agent/...`) and opens a pull request for review.
- Keep requests explicit: what to change, where, and how to verify it.

Edit this file to describe the project.

## Getting Started

安装依赖：

```bash
npm install
```

启动本地开发服务器：

```bash
npm run dev
```

构建生产版本：

```bash
npm run build
```
